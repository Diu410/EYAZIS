# Примеры для лабораторной 3

Четыре TXT-документа по **20 000 символов** каждый:

| Файл | Язык | Предметная область |
| --- | --- | --- |
| `sample_ru_computer_science.txt` | Русский | Информатика |
| `sample_ru_literature.txt` | Русский | Литература |
| `sample_de_computer_science.txt` | Немецкий | Информатика |
| `sample_de_literature.txt` | Немецкий | Литература |

Откройте «Реферирование» → «Загрузить текстовый файл», выберите один пример и укажите соответствующий язык. Введите название и предметную область, затем нажмите «Построить реферат». Покажите десять предложений реферата, список ключевых слов с весами и раскрывающуюся таблицу весов всех предложений. Результат можно сохранить в TXT или JSON.

Те же тексты доступны карточками «Тестовая коллекция» прямо на странице приложения: при выборе карточки язык и предметная область заполняются автоматически. Файлы скопированы из `lab3/corpus/`; адреса исходных статей находятся в `lab3/corpus/sources.json`. Для обычного реферирования OSTIS не требуется.
