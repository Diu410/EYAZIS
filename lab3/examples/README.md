# Примеры для лабораторной 3

Четыре полных учебных авторских TXT-документа по **4500 символов** каждый, подготовленных с помощью ИИ:

| Файл | Язык | Предметная область |
| --- | --- | --- |
| `sample_ru_computer_science.txt` | Русский | Информатика |
| `sample_ru_literature.txt` | Русский | Литература |
| `sample_de_computer_science.txt` | Немецкий | Информатика |
| `sample_de_literature.txt` | Немецкий | Литература |

Запустите Ollama с установленной `qwen3.5:4b`. Откройте «Реферирование» → «Загрузить текстовый файл», выберите пример и укажите соответствующий язык. Введите название и предметную область, оставьте метод «Генеративный — Qwen 3.5 4B» и нажмите «Построить реферат». Покажите связный реферат, название модели, время генерации и ключевые слова исходника с весами TF·IDF. Результат можно сохранить в TXT или JSON, распечатать и открыть сохранённый исходник.

Для сравнения загрузите тот же текст и выберите «Экстрактивный — TF·IDF»: он возвращает предложения исходника с наибольшими весами, сохраняя их порядок. Генеративный метод переформулирует содержание. Число предложений — верхний предел, особенно для коротких документов.

Те же тексты доступны карточками «Тестовая коллекция» прямо на странице приложения: язык и предметная область заполняются автоматически. Файлы скопированы из `lab3/corpus/`; жанры и происхождение указаны в `lab3/corpus/sources.json`. Это научные учебные статьи об алгоритмах и литературные сочинения о Достоевском, а не фрагменты Wikipedia. Генеративный режим работает с локальной моделью; экстрактивный — без модели.
