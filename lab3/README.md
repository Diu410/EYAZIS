# Лабораторная работа 3: реферирование документов

`summarizer.py` содержит экстрактивное реферирование русского и немецкого текста. `ostis_client.py` необязательно сохраняет готовый результат в sc-machine через WebSocket `sc-server`; алгоритм реферирования от него не зависит.

Главная функция — `summarize(document, language="ru", reference_documents=None, max_sentences=10, max_keywords=20, subject_area=None)`. Она возвращает исходный документ, предложения реферата в исходном порядке, ключевые слова с весами, оценки всех предложений, язык и, если задана, предметную область.

## Работа через приложение

1. Из корня проекта запустите `python app.py` и откройте <http://127.0.0.1:8765>.
2. Выберите «Реферирование» в разделе лабораторной 3. Откройте один из четырёх текстов тестовой коллекции или вставьте свой текст. Также можно загрузить TXT/MD-файл либо нажать «Реферировать» на странице документа лабораторной 1 или 2.
3. Укажите язык (`ru` или `de`), предметную область при необходимости и количество предложений. Нажмите «Построить реферат».
4. Просмотрите классический реферат, список ключевых слов с весами и раскрывающуюся таблицу оценок всех предложений. Результат автоматически сохраняется в SQLite и остаётся доступен из списка «Сохранённые рефераты».
5. Скачайте TXT или JSON, либо нажмите «Распечатать». Исходный документ открывается по активной ссылке, когда для него известен URL или он взят из другой лабораторной работы. Локально сохранённый реферат можно удалить из списка или со страницы результата.

Методичка описывает классический реферат как выбор наиболее информативных предложений и рекомендует около **10 предложений**. Если исходный текст содержит только 3 предложения, алгоритм вернёт максимум 3: это почти копия исходника. Приложение предупреждает об этом и показывает число выбранных предложений и степень сокращения. Для демонстрации используйте длинный текст из тестовой коллекции.

Тестовая коллекция находится в `lab3/corpus/`: четыре документа на русском и немецком языках по 20 000 символов каждый, посвящённые информатике и литературе. Источники записаны в `lab3/corpus/sources.json`. Чтобы подготовить эти файлы заново, выполните `python -m lab3.prepare_corpus` при наличии интернета. Эти тексты служат демонстрацией; для сравнения рефератов на собственной коллекции используйте документы одинакового объёма.

Веб-интерфейс сохраняет результаты в таблицу `summaries` базы `eyazis.sqlite3`. Он не меняет алгоритм `summarize()`.

Пример:

```python
from lab3 import summarize

result = summarize("Первое предложение. Второе предложение.", language="ru")
print(result["summary"])
print(result["keywords"])
```

Вес слова: `0.5 × (1 + TF(t,D)/TFmax(D)) × ln(|DB|/DF(t))`. Лексический вес предложения: `Σ TF(t,Si) × w(t,D)`. Итоговый вес: лексический вес × `(1 − BD(Si)/|D|)` × `(1 − BP(Si)/|P|)`. Параметр `reference_documents` позволяет передать внешнюю коллекцию для IDF. Без неё документ делится на абзацы; если абзац один, на предложения. В русском тексте исключаются числа, латинские слова и стоп-слова. В немецком латинские слова сохраняются, иначе анализ языка варианта 4 был бы невозможен.

## Необязательное сохранение в OSTIS

Используется официальный [py-sc-client](https://github.com/ostis-ai/py-sc-client) с [sc-server из sc-machine](https://github.com/ostis-ai/sc-machine). Клиент версии 0.4.0 документирует совместимость со sc-machine 0.10.0. Для Windows сервер запускается через Docker по [официальной инструкции](https://ostis-ai.github.io/sc-machine/quick_start/); полная ostis-web-platform не нужна.

Для демонстрации в этом проекте клиент уже установлен в `.venv`. Откройте Docker Desktop и выполните из корня проекта в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\lab3\start_ostis.ps1
.\.venv\Scripts\python.exe app.py
```

Скрипт один раз собирает базу знаний в Docker и запускает `sc-server` на `ws://localhost:8090/ws_json`. Откройте <http://127.0.0.1:8765>, перейдите в лабораторную 3, постройте реферат по тексту из `lab3/examples/`, затем на странице результата нажмите «Записать в OSTIS». Успешная запись будет показана на этой же странице.

### Как посмотреть запись в OSTIS

При работающем `sc-server` выполните из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m lab3.view_ostis
```

Команда выводит адреса записанных документов и начало каждого текста. Подставьте нужный адрес вместо `SC_ADDR`:

```powershell
.\.venv\Scripts\python.exe -m lab3.view_ostis --document SC_ADDR
.\.venv\Scripts\python.exe -m lab3.view_ostis --document SC_ADDR --scores
```

Первая команда читает из OSTIS исходный текст, реферат, ключевые слова с весами, язык, предметную область и число оценённых предложений. Вторая дополнительно выводит оценки каждого предложения. Это чтение напрямую из sc-server, а не из SQLite. В браузере пока показывается только подтверждение записи: `sc-server` сам по себе не предоставляет страницу просмотра этих данных.

Для остановки сервера:

```powershell
docker-compose -f .\lab3\ostis-compose.yml down
```

Если локальное окружение `.venv` отсутствует, установите клиент заново:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r lab3\requirements-ostis.txt
```

Для другого сервера задайте переменную `SC_SERVER_URL` с его WebSocket-адресом. Программный вызов из корня проекта:

```python
from lab3 import summarize, save_to_ostis

result = summarize(
    "Алгоритм обрабатывает данные. Модель оценивает результат.",
    language="ru",
    subject_area="computer science",
)
saved = save_to_ostis(result)  # True при успехе, False если клиент/сервер недоступен
print(result["summary"], saved)
```

В веб-интерфейсе откройте готовый реферат и нажмите «Записать в OSTIS». При недоступном сервере сохранённый в SQLite реферат остаётся доступен. Результат работы OSTIS показывается на той же странице.

В OSTIS создаются узлы `Document → Summary → Sentence`, `Document → Keyword`, записи оценок всех предложений, язык и предметная область. Тексты и численные значения хранятся в ссылках с именованными отношениями. Сервер не нужен для вызова `summarize()`. Если запись не удалась, `save_to_ostis` возвращает `False` и выдаёт предупреждение; `strict=True` превращает ошибку сохранения в исключение. Повторный вызов создаёт новую запись документа.
