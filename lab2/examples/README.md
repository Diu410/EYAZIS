# Примеры для лабораторной 2

Это четыре HTML-документа примерно одинакового объёма (около 3000 символов текста). Два русских файла: `test_ru_1.html` (машинное обучение) и `test_ru_3.html` (программирование). Два немецких: `test_de_1.html` (Maschinelles Lernen) и `test_de_3.html` (Programmierung).

Откройте «Язык текста» → «Добавить HTML-файлы». Сначала выберите **оба русских** файла, в поле «Известный язык» укажите «Русский» и нажмите «Распознать». Затем так же загрузите **оба немецких** файла с меткой «Немецкий». Метка назначается сразу всем файлам, выбранным за один раз. После загрузки можно открыть каждый результат, показать ответы трёх методов, точность и время работы, сохранить CSV.

Файлы скопированы из `lab2/corpus/`; адреса исходных статей указаны в `lab2/corpus/sources.json`. Если файлы с такими именами уже загружены, повторный выбор создаст отдельные записи. Ненужные результаты можно удалить из таблицы на странице «Язык текста».
