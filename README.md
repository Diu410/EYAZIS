# Лабораторные работы по ИПС — вариант 4

Локальное веб-приложение на Python и SQLite. Работы решают отдельные задачи; общий веб-интерфейс и SQLite используются повторно. Код каждой работы лежит в своей папке: `lab1/`, `lab2/`, `lab3/`. Все три работы доступны через общую оболочку. Отчёты находятся в папке `report/`.

## Запуск

Нужен Python 3.10 или новее. Для работы самого приложения сторонние пакеты не требуются.

```powershell
python app.py
```

Откройте <http://127.0.0.1:8765>. На стартовой странице выберите лабораторную работу. Для другого порта: `python app.py --port 9000`.

База `eyazis.sqlite3` создаётся автоматически. В рабочей папке уже есть демонстрационные данные. Чтобы сформировать коллекцию заново в пустой базе:

```powershell
python -m lab2.prepare_corpus
python -m lab3.prepare_corpus
python -m lab1.seed
```

Скрипты `prepare_corpus.py` загружают тексты из Wikipedia; для них нужен интернет. Подготовленные коллекции уже лежат в `lab2/corpus/` и `lab3/corpus/`, поэтому обычный запуск приложения сети не требует. Источники указаны в `sources.json` каждой коллекции.

Для показа преподавателю подготовлены отдельные папки `lab1/examples/`, `lab2/examples/` и `lab3/examples/`. В каждой лежат файлы для загрузки и короткая инструкция `README.md` с действиями в интерфейсе.

## Лабораторная 1

Разделы «Документы», «Поиск», «Оценка поиска». Поддерживаются ручное добавление русскоязычного текста, выбор TXT/MD-файла и импорт HTML-страницы по URL. Загруженный документ можно удалить из списка или со страницы документа. Запрос в поиске вводится свободно. Ключевые слова индексируются автоматически. Вес термина равен `TF × ln(N/DF)`, ранг — косинусной близости вектора документа и бинарного вектора запроса.

Оценка считает точность, полноту, F1, P@10, AP и R-точность и строит 11-точечный интерполированный график точности от полноты. Раздел «Оценка поиска» принимает любой запрос. Для четырёх подготовленных запросов используются независимые эталонные оценки релевантности на фиксированной коллекции из десяти документов. Для остальных запросов программа автоматически создаёт ориентировочную псевдоразметку на всех загруженных документах: релевантными считаются документы с наибольшим числом совпавших значимых слов запроса. Это позволяет показать метрики и график, но такая автооценка не является независимой проверкой качества поиска. Если ни одно слово не найдено, метрики не определены и график не строится. Отдельный PDF `2004_romip_metrix.pdf`, упомянутый в задании, в исходной папке отсутствовал; точность, полнота и 11-точечный график выбраны по опубликованной [методике РОМИП](https://romip.narod.ru/en/2006/tracks/legal-adhoc.html).

## Лабораторная 2

Раздел «Язык текста» принимает пользовательские HTML-файлы; отдельные примеры для демонстрации находятся в `lab2/examples/`. Загруженные результаты можно удалить из таблицы или со страницы документа. Обучающие наборы русского и немецкого языков лежат в `lab2/corpus/train_ru.txt` и `lab2/corpus/train_de.txt`; размер каждого — от 20 до 120 КБ. Тестовые документы содержат по 3000 символов текста.

Методы: N-граммы длиной до пяти символов с метрикой Out Of Place; частотные профили алфавита с косинусным сравнением; небольшая нейронная сеть с одним скрытым слоем, обучаемая на фрагментах корпуса. Сводная таблица показывает точность на размеченных текстах и среднее время распознавания. Результаты можно сохранить в CSV или напечатать из браузера.

## Лабораторная 3 — реферирование

Откройте «Реферирование», выберите один из четырёх примеров одинаковой длины, вставьте собственный текст, загрузите TXT/MD-файл или перейдите к реферированию со страницы документа из первой или второй работы. Выберите русский или немецкий язык и при необходимости предметную область. Классический реферат по методичке состоит примерно из десяти самых весомых предложений исходного документа; для наглядного сокращения нужен длинный исходный текст. При обработке короткого текста приложение предупреждает, что реферат почти повторяет оригинал. Также показываются ключевые слова с весами TF·IDF, оценки предложений и степень сокращения. Результат сохраняется в SQLite; его можно скачать в TXT/JSON, распечатать или удалить локально.

Функция `lab3.summarize(document, language="ru", reference_documents=None)` остаётся отдельной от веб-интерфейса. Кнопка «Записать в OSTIS» использует необязательный модуль `lab3.ostis_client`; для реферирования работающий OSTIS не нужен. Для демонстрации OSTIS запустите Docker Desktop, выполните `powershell -ExecutionPolicy Bypass -File .\lab3\start_ostis.ps1`, затем `.\.venv\Scripts\python.exe app.py`. Пошаговая инструкция и формулы — в `lab3/README.md`.
