# Синтаксический разбор

Дерево выбранного предложения строится локальным spaCy en_core_web_sm 3.8.0.
Gemma используется для перевода и словаря, но не для генерации дерева.

Зависимости: `python -m pip install -r lab4/requirements.txt`.
Модель установлена в `lab4/models/en_core_web_sm`.

Анализатор загружается один раз при первом разборе. Далее используется повторно.
Проверяются корни, отсутствие циклов и корректность индексов связей. Если
выделенный текст включает несколько предложений, у каждого будет своё дерево.
Узлы содержат исходные токены, части речи и отношения зависимостей.

В интерфейсе дерево отображается как схема с корнем наверху, узлами-словами
и линиями с подписями зависимостей. Масштаб можно менять ползунком или кнопкой
«Вписать в окно»; большие деревья прокручиваются внутри схемы. При выборе
другого предложения показывается его сохранённое дерево. Текстовая версия
доступна в раскрывающемся блоке для копирования и в TXT-экспорте.

Разборы сохраняются в SQLite. Старый разбор Gemma при следующем запросе
автоматически заменяется разбором spaCy. Модель анализатора хранится локально;
во время обработки текста загрузка из интернета не требуется.
