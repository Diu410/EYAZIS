# Лабораторные 5–7

Разделы `/speech/5`, `/speech/6`, `/speech/7`: результаты опытов, аудиоматериалы,
осциллограммы, контуры F₀/RMS и отчёты. Источник заданий — PDF в корне проекта.

## Запуск

```powershell
.\.venv\Scripts\python.exe app.py
```

Адрес: `http://127.0.0.1:8765/speech/5`. Зависимость обработки — NumPy.
Записи, разметка и результаты находятся в таблицах `speech_clips`,
`speech_experiments`, `speech_notes` базы `eyazis.sqlite3`.

## Воспроизведение опытов

```powershell
.\.venv\Scripts\python.exe -m speech.experiments
```

Код лабораторных расположен в папке `lab 5-7`; файл `speech.py` в корне
сохраняет путь импорта `speech` и команды запуска модулей.
Исходники и порядок произнесения заданы в `lab 5-7/session.json`.
Другая сессия задаётся параметром `--session файл.json`. Производные записи
имеют стабильные ключи; повторный запуск сохраняет аудио исходников и оценки.

## Методы

- WAV PCM 8/16/24/32 бит, 4–96 кГц; анализ стерео по среднему каналов.
- Ресемплинг Фурье с ограничением полосы; восемь форматов качества из одного исходника.
- Независимое изменение длительности и тона: фазовый вокодер STFT,
  окно 1024 отсчёта, шаг 256. Pitch Bend меняет скорость воспроизведения.
- F₀: автокорреляция окна Ханна 40 мс с поправкой на перекрытие,
  диапазон 60–500 Гц, порог корреляции 0,55. Базовый порог RMS 0,005;
  при наличии пауз — не менее 1,5 оценки фонового уровня.
- Энергия: RMS нормированного PCM. Осциллограмма: минимумы и максимумы отсчётов.
- Внешние границы сегментов: огибающая. Слова: приближённое DTW-выравнивание
  спектральных признаков. Внутрислоговые согласные: оценка спектральных переходов.
- Фонемная база: материал лабораторной 5. Слоговая база: независимые записи работ 5 и 7.
- Отчёт ZIP: HTML, WAV, SVG, CSV и JSON с разметкой и параметрами обработки.
