# Примеры для лабораторной 1

Откройте «Документы» → «Выбрать пример или свой TXT-файл», выберите один файл из этой папки и нажмите «Добавить документ». Повторите для остальных файлов. Имя файла подставится как заголовок, текст — в поле документа.

Для демонстрации поиска введите запрос **«поиск документов»**: наиболее близки документы `01_search_engines.txt` и `02_vector_search.txt`. Запрос **«нейронная сеть обучение»** должен вывести материал `04_neural_networks.txt`, а **«база данных SQLite»** — `03_database.txt`.

В «Оценке поиска» можно вписать любой запрос и получить метрики с графиком. Для четырёх предложенных запросов используются эталонные оценки на фиксированной коллекции из десяти документов. Для остальных запросов программа строит ориентировочную автооценку по совпадению слов на всех загруженных документах; она не заменяет независимую экспертную оценку качества поиска.
