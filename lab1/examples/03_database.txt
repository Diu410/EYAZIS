База данных хранит сведения в таблицах. В реляционной базе таблица состоит из строк и столбцов, а ключи связывают записи между собой. SQLite сохраняет всю базу в одном файле и подходит для небольшого локального приложения.

Запрос SQL выбирает строки по заданным условиям. Индекс базы данных ускоряет поиск записей по значениям столбца. Например, приложение может хранить в таблице документы, их названия и исходные тексты, а в другой таблице — слова и частоты этих слов. Транзакции помогают сохранить данные согласованными при изменениях.
