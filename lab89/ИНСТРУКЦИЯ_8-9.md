# Лабораторные 8–9: развёртывание и запуск моделей

Общая страница позволяет озвучить французский текст в лабораторной 8 и распознать полученную запись в лабораторной 9. Локальный синтез выполняет Piper, распознавание — Whisper large-v3-turbo через faster-whisper и CTranslate2. Движки работают в отдельных Docker-контейнерах, веб-приложение запускается отдельно в Windows.

## Что необходимо

- Запущенный Docker Desktop с Linux-контейнерами и Docker Compose; Python с зависимостями, необходимыми для запуска существующего приложения. Можно использовать уже настроенное окружение проекта.
- Для настроенного режима Whisper — видеокарта NVIDIA, совместимый драйвер и доступ GPU из Docker Desktop/WSL 2. Текущая конфигурация использует CUDA и `int8_float16`; автоматического перехода на CPU нет.
- Интернет для скачивания Docker-образов, пакетов и моделей. После успешной загрузки моделей локальные Piper и Whisper работают без интернета. Перевод через Groq и облачные варианты используют сеть.
- Несколько гигабайт свободного места в хранилище Docker и место в проекте для записей.

Все команды выполняются в PowerShell из корня вашего клона репозитория. Например:

```powershell
cd 'ПУТЬ_К_ВАШЕЙ_ПАПКЕ\EYAZIS'
```

## Первое развёртывание

1. Запустите Docker Desktop и проверьте инструменты и видеокарту:

   ```powershell
   docker version
   docker compose version
   nvidia-smi
   ```

   `nvidia-smi` в Windows подтверждает, что драйвер видит GPU. Доступ из контейнера проверяется отдельно ниже.

2. Соберите и запустите оба контейнера:

   ```powershell
   docker compose -f lab89/local/compose.yaml up -d --build
   ```

   При первой сборке скачиваются образы и пакеты; CUDA-образ большой. Чтобы собрать один сервис, добавьте в конце команды `piper` или `whisper`. Если скачивание прервалось, повторите команду.

3. Проверьте состояние и доступ GPU:

   ```powershell
   docker compose -f lab89/local/compose.yaml ps
   docker compose -f lab89/local/compose.yaml exec whisper nvidia-smi
   ```

   Оба контейнера должны работать. Если GPU внутри контейнера не видна, проверьте настройки Docker Desktop, WSL и драйвер NVIDIA.

4. В отдельном окне PowerShell из корня проекта запустите приложение. При уже настроенном Python-окружении:

   ```powershell
   python app.py --port 8878
   ```

   Для нового виртуального окружения см. [инструкцию приложения](README.md): ему также нужны зависимости существующих лабораторных. Пакет `edge-tts` необходим только для сетевых голосов Microsoft.

   Оставьте окно открытым и перейдите на http://127.0.0.1:8878/lab8. Если порт уже занят работающим приложением проекта, откройте его страницу; второй экземпляр на том же порту не запустится.

5. Модели скачиваются **при первом запросе**, а не при сборке. Выберите голос `Siwis · fr-FR · Piper локально` и нажмите «Озвучить и сохранить». Затем выберите локальный Whisper и запустите распознавание записи. Первый запрос может занять продолжительное время. Следить за журналом можно в другом окне:

   ```powershell
   docker compose -f lab89/local/compose.yaml logs -f piper
   docker compose -f lab89/local/compose.yaml logs -f whisper
   ```

   `Ctrl+C` завершает просмотр журнала, не останавливая контейнер.

## Проверка работы

1. Выберите один из пяти учебных текстов в списке и нажмите «Загрузить пример», либо введите свой текст, например `Un algorithme de recherche analyse les données et classe les documents.`
2. Выберите локальный Piper, нажмите «Озвучить и сохранить» и дождитесь воспроизведения. MP3 появится в коллекции ниже.
3. В разделе распознавания выберите локальный Whisper и созданную запись, затем нажмите «Распознать запись».
4. Сравните результат с исходным французским текстом: пунктуация может отличаться, возможны ошибки распознавания.
5. Можно выбрать ранее сохранённую запись, загрузить файл либо записать речь с микрофона. Форматы: WAV, MP3, M4A, MP4, WEBM, OGG, FLAC; до 10 МиБ.

Проверка доступности HTTP-сервисов:

```powershell
Invoke-RestMethod http://127.0.0.1:8899/health
Invoke-RestMethod http://127.0.0.1:8900/health
```

Ответ означает, что процесс сервиса отвечает; `piper_loaded` или `whisper_loaded` становится `true` только после загрузки соответствующей модели. Проверяйте поле соответствующего сервиса. Один только ответ `/health` не подтверждает успешную загрузку модели или работу GPU.

## Последующие запуски и остановка

Запустите Docker Desktop, затем из корня проекта:

```powershell
docker compose -f lab89/local/compose.yaml up -d
python app.py --port 8878
```

Откройте http://127.0.0.1:8878/lab8. Если контейнеры ещё не собраны или изменился их код, используйте `up -d --build`.

Остановить контейнеры, сохранив модели:

```powershell
docker compose -f lab89/local/compose.yaml stop
```

Приложение останавливается через `Ctrl+C` в окне с `app.py`. Команда `docker compose ... down -v` удалит том моделей; без необходимости её не используйте.

## Устройство и хранение данных

- Piper: модель `fr_FR-siwis-medium`, CPU; сформированный WAV внутри контейнера преобразуется в MP3. Скорость управляется через `length_scale`.
- Whisper: `faster-whisper==1.2.1`, псевдоним `turbo` выбирает CTranslate2-модель `mobiuslabsgmbh/faster-whisper-large-v3-turbo`; CUDA, `int8_float16`, французский язык, транскрибация и `beam_size=5`. Выполняется распознавание французской речи, а не перевод.
- Кэш моделей хранится в Docker volume `local_speech-models`; другое имя Compose-проекта может дать другой префикс тома.
- MP3 и описания записей находятся в `lab89/recordings/` в директории проекта, отдельно от тома моделей. Сохранённая озвучка появляется в списке лабораторной 9.
- Пять учебных текстов лежат в `lab89/examples/`, пять озвучек с метаданными включены в репозиторий. Приложение находит их относительно собственных файлов; после `git pull` коллега увидит их в списках на своей машине.
- При указанной команде сайт слушает `127.0.0.1:8878`; контейнеры опубликованы на `127.0.0.1:8899` и `127.0.0.1:8900`.

## Если возникла ошибка

| Симптом | Что проверить |
| --- | --- |
| `Локальный сервис недоступен` | Запущен ли Docker Desktop; показывает ли `docker compose ... ps` нужный контейнер; при необходимости выполнить `up -d --build`. |
| Сборка зависла или произошёл сетевой тайм-аут | Интернет и доступ к Docker-реестру; повторить сборку. Ход сборки виден в выводе команды сборки, а не в `logs` контейнера. |
| Контейнер работает, но первый запрос не заканчивается | Журнал конкретного сервиса, скачивание модели, доступ к Hugging Face и место на диске. |
| Ошибка CUDA или нехватка видеопамяти | `nvidia-smi` в Windows и внутри контейнера, свободную видеопамять и драйвер. Закрыть другие приложения, занимающие GPU. На облако и CPU сервис автоматически не переключается. |
| Не открывается сайт | Запущен ли `python app.py --port 8878`, правильный ли порт и не занят ли он другим приложением. |
| Нет звука или записи | Выбранный голос, статус синтеза и громкость; обновите список записей. Браузерные голоса работают без сохранения. |

Microsoft Edge TTS и Groq выбираются отдельно и используют интернет. Для Groq нужен `GROQ_API_KEY` в переменной окружения либо в `%LOCALAPPDATA%\TgAgent\secrets\.env.groq`. Для Edge TTS приложению нужен пакет из `lab89/requirements.txt`. Для локальных Piper и Whisper ключ не нужен.
