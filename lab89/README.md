# Лабораторные 8 и 9

Вариант 4: французский язык, информатика. Лабораторная 8 озвучивает текст через локальный Piper, Microsoft Edge TTS (Denise и Henri, интернет) либо доступные французские голоса браузера. Лабораторная 9 распознаёт аудио локальным Whisper через faster-whisper или через Groq Whisper `whisper-large-v3-turbo`, язык `fr`. Распознанная фраза сопоставляется с фиксированным списком команд; неизвестные фразы ничего не выполняют.

Для локальных моделей см. [инструкцию по развёртыванию и запуску](ИНСТРУКЦИЯ_8-9.md). Приложение и Docker-сервисы запускаются отдельно.

## Запуск на Windows

```powershell
python -m venv --system-site-packages .venv
.\.venv\Scripts\python.exe -m pip install -r lab89\requirements.txt
.\.venv\Scripts\python.exe app.py --port 8878
```

Основному приложению также нужен NumPy из `lab 5-7/requirements.txt`; если он не установлен в системном Python, установите его в это окружение. Откройте `http://127.0.0.1:8878/lab8` или `/lab9`. Для записи разрешите браузеру доступ к микрофону. Edge TTS использует внешний сетевой сервис и не является официальным SDK Microsoft; браузерные голоса могут отсутствовать или также быть сетевыми.

Ключ Groq передаётся серверу через `GROQ_API_KEY` или читается из существующего локального `%LOCALAPPDATA%\TgAgent\secrets\.env.groq`. В браузер ключ не отправляется. При выборе Groq аудио отправляется в Groq; при выборе Edge TTS текст — в Microsoft. Возможна тарификация Groq. Локальные Piper и Whisper ключа не требуют. Аудио и транскрипция лабораторной 9 в базу проектом не записываются. Текст поля хранится в localStorage браузера, чтобы обе лабораторные могли работать с одним текстом.

Команды произносятся отдельно после нажатия «Начать запись»; для запуска распознавания запись нужно остановить. Можно выбрать WAV/MP3/M4A/MP4/WEBM/OGG/FLAC до 10 МБ. Результат модели не гарантированно точен: слушайте запись и проверяйте отображённую фразу и реакцию.

В лабораторной 8 можно выбрать один из пяти учебных текстов и нажать «Загрузить пример», ввести свой французский текст или перевести русский через Groq `openai/gpt-oss-20b`; перевод проверьте перед озвучиванием. После успешного синтеза Piper или голосами Microsoft MP3 и текст автоматически сохраняются в `lab89/recordings/`. Пять учебных записей включены в Git, новые пользовательские записи по умолчанию игнорируются. Громкость изменяет воспроизведение в браузере, а не записанный MP3. В лабораторной 9 выберите запись из общей коллекции, прослушайте или скачайте её и отправьте на транскрибацию. Браузерные голоса не создают сохраняемый MP3. В `examples/` лежат французские учебные материалы.
