# Лабораторные 8 и 9

Вариант 4: французский язык, информатика. Лабораторная 8 озвучивает текст через локальный французский Piper или Microsoft Edge TTS. Лабораторная 9 распознаёт французский, русский, английский или немецкий через локальный faster-whisper или Groq Whisper `whisper-large-v3-turbo`. Распознанная фраза сопоставляется со списком команд для выбранного языка; остальные фразы сохраняются как последние произнесённые.

Для локальных моделей см. [инструкцию по развёртыванию и запуску](ИНСТРУКЦИЯ_8-9.md). Приложение и Docker-сервисы запускаются отдельно.

## Запуск на Windows

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r lab89\requirements.txt
.\.venv\Scripts\python.exe app.py --port 8878
```

Зависимости лабораторных 8–9, включая NumPy и ONNX Runtime, перечислены в `lab89/requirements.txt`. Для остальных лабораторных могут потребоваться дополнительные зависимости. Откройте `http://127.0.0.1:8878/lab8` или `/lab9`. Для записи разрешите браузеру доступ к микрофону. Edge TTS использует внешний сетевой сервис и не является официальным SDK Microsoft.

Ключ Groq читается сначала из переменной `GROQ_API_KEY`, затем из `.env.groq` в корне проекта и, если ключ там отсутствует, из `%LOCALAPPDATA%\TgAgent\secrets\.env.groq`. Формат файла: `GROQ_API_KEY=ваш_ключ`. Файл в корне проекта исключён из Git; в браузер ключ не отправляется. При выборе Groq аудио отправляется в Groq; при выборе Edge TTS текст — в Microsoft. Возможна тарификация Groq. Локальные Piper и Whisper ключа не требуют. Аудио и транскрипция лабораторной 9 в базу проектом не записываются. Текст поля хранится в localStorage браузера.

Выберите язык, нажмите «Включить микрофон» и разрешите доступ браузеру. Локальная модель Silero VAD выделяет речевые фрагменты; после паузы фрагмент автоматически отправляется в выбранный Whisper с выбранным языком, текст добавляется в результат, а распознанная команда выполняется. Микрофон продолжает слушать до нажатия «Остановить микрофон» или соответствующей голосовой команды. Нужны зависимости `numpy` и `onnxruntime` из `lab89/requirements.txt`; веса Silero `lab89/models/silero_vad_v6.onnx` работают на CPU. По умолчанию выбраны Groq для распознавания и Microsoft Edge для озвучки; локальные движки остаются доступными. Для ручной проверки можно выбрать WAV/MP3/M4A/MP4/WEBM/OGG/FLAC до 10 МБ. Распознавание не гарантирует точности: проверяйте отображённую фразу и реакцию.

Команды произносятся отдельными фразами на выбранном языке. Например: «читай», «команды», «смени язык», «останови распознавание»; `read`, `commands`, `change language`, `stop listening`; `lies`, `befehle`, `sprache wechseln`, `aufnahme stoppen`; `lis`, `commandes`, `change de langue`, `arrête le micro`. Для коротких французских команд система также сопоставляет варианты распознавания `Lise` с `lis`, а `Command this` с `commandes`, если соответствующие команды включены. Распознанный текст при этом не исправляется. Полный список и варианты — в разделе «Голосовые команды», отдельно для каждого языка. Можно менять фразы и включать или отключать действия; настройки сохраняются в текущем браузере. Смена языка идёт по кругу французский → русский → английский → немецкий → французский и действует на следующий запрос распознавания. Уже отправленный запрос обрабатывается на предыдущем языке.

Команда чтения озвучивает последнюю распознанную фразу, которая не была командой; если такой нет, используется поле текста лабораторной 8. Когда выбранный голос не соответствует языку фразы, автоматически используется голос Microsoft этого языка. Скорость и громкость регулируют воспроизведение созданного аудиофайла, сам файл создаётся с обычной скоростью. Используйте гарнитуру или уменьшите звук динамиков, если микрофон слышит внешнее воспроизведение.

В лабораторной 8 можно выбрать учебный текст с пометкой FR, RU, EN или DE: текст и его язык выбираются автоматически, а список голосов ограничен соответствующим языком. Для текста, введённого вручную, язык выбирается в поле «Язык текста»; автоматического определения языка нет. Несоответствие русского алфавита и выбранного голоса проверяется отдельно, но смешанные тексты нужно проверять самостоятельно. Также можно перевести русский текст через Groq `openai/gpt-oss-20b`; перевод проверьте перед озвучиванием. После синтеза MP3 и текст сохраняются в `lab89/recordings/`. Пять учебных записей включены в Git, новые пользовательские записи по умолчанию игнорируются. Скорость и громкость изменяют воспроизведение в браузере, а не записанный MP3. В лабораторной 9 запись можно выбрать, прослушать, скачать, распознать или удалить крестиком прямо в раскрытом списке. Для одинакового текста варианты озвучки группируются, а удаляется только выбранный вариант.
