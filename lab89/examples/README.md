# Учебные французские тексты

Это краткие оригинальные учебные пересказы по теме информатики, не дословные выдержки из научных статей. Подготовлены для демонстрации синтеза и распознавания речи.

- `01_recherche.txt` — поиск документов, индекс, точность и полнота; справочный источник: https://interstices.info/algorithmes-mode-demploi/
- `02_apprentissage.txt` — обучение по примерам и обобщающая способность; справочный источник: https://chercheurs.lille.inria.fr/pgermain/publis/memoire.pdf
- `03_bases_de_donnees.txt` — реляционные базы данных, SQL и транзакции.
- `04_reseaux.txt` — компьютерные сети, IP, TCP, задержка и пропускная способность.
- `05_securite.txt` — основы информационной безопасности.

Пять готовых MP3 и их метаданные включены в репозиторий в `lab89/recordings/` и доступны из лабораторной 9 сразу после клонирования. Голос — Microsoft `fr-FR-DeniseNeural`. Остальные пользовательские записи не добавляются в Git автоматически.
