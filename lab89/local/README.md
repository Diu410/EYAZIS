# Локальный синтез и распознавание для лабораторных 8–9

Подробное руководство: [инструкция по развёртыванию и запуску](../ИНСТРУКЦИЯ_8-9.md).

Из корня проекта запустить Docker Desktop и выполнить:

```powershell
docker compose -f lab89/local/compose.yaml up -d --build
```

Открыть страницу лабораторных 8–9 в приложении. Для синтеза выбрать голос Piper Siwis, для распознавания — локальный Whisper. Результат синтеза сохраняется в коллекцию MP3 и сразу доступен для лабораторной 9. Microsoft и Groq остаются доступными отдельно; перевод русского текста использует Groq.

В отдельных контейнерах Piper `fr_FR-siwis-medium` работает на CPU, faster-whisper использует модель `large-v3-turbo` в формате CTranslate2 на NVIDIA GPU (`int8_float16`). Модели скачиваются при первом обращении и сохраняются в Docker volume `local_speech-models`. Первая операция может занять значительное время, потребуется интернет и несколько гигабайт свободного места; последующие операции выполняются без сети. Приложение запускается отдельно от контейнеров.

Проверка состояния и журнала:

```powershell
docker compose -f lab89/local/compose.yaml ps
docker compose -f lab89/local/compose.yaml logs -f
```

Остановить контейнер без удаления моделей: `docker compose -f lab89/local/compose.yaml stop`. Не используйте `down -v`, если хотите сохранить скачанные модели. Для GPU необходим доступ Docker к NVIDIA GPU; при ошибке смотрите журнал, автоматического перехода в облако нет.
