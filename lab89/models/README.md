# Silero VAD

`silero_vad_v6.onnx` — модель для детектирования речи, полученная из пакета faster-whisper 1.2.1 (`faster_whisper/assets/silero_vad_v6.onnx`). Применяется локально на CPU через ONNX Runtime; она определяет речевую активность, но не распознаёт слова.

Источники: https://github.com/SYSTRAN/faster-whisper и https://github.com/snakers4/silero-vad. Лицензии находятся рядом с моделью.
